# Contributing

Thanks for helping out! Here's how.

## Reporting a problem

[Open an issue](../../issues/new/choose) and pick **Something isn't working**. Please include your keyboard version (it's on the sticker under the keyboard) and whether you use the cable or the dongle.

## Confirming your keyboard works

Have a K708 version that isn't listed under "Tested on" in the README? Open an issue with **It works on my keyboard**. It helps other people know it's safe to try.

## Changing the code

1. Fork the repo and make your change.
2. Test it: copy `plugin/Redragon_K708_Pro.js` into `Documents\WhirlwindFX\Plugins` and restart SignalRGB.
3. If your change touches how colors are sent, run the [Key Check page](https://hamza-elakly.github.io/Redragon-K708-signalrgb-plugin/tools/key-check.html) with SignalRGB closed and then running, and mention the results.
4. Open a pull request describing what you changed and how you tested it.

Keep changes small and focused. One fix or feature per pull request is easiest to review.
