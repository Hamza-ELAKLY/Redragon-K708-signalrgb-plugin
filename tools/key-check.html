Reading the results

  • Double presses are two presses of the same key less than 60 ms apart. Human fingers can't do that, so it's the switch or the keyboard's chip. If run B has more than run A, set the plugin's Packet size to 24.
  • Missed key releases mean a key went down a second time with no release in between. That's a dropped event, the clearest sign the chip is overloaded.
  • Extra and dropped characters in the typing test show doubled or lost keystrokes in normal use. One or two can be your own typing, so only a clear jump from A to B matters.
  • This page can't measure true input lag in milliseconds, because a browser only sees when Windows delivers the key. If B feels sluggish even with clean numbers, turn on Low frame-rate mode and try packet size 24.
